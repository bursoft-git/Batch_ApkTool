## Русский

Batch ApkTool - это мощная оболочка, объединяющая несколько инструментов для работы с файлами APK и взаимодействия с устройством через adb.

### 🚀 Скачать
Вы можете скачать последнюю версию в формате ZIP [здесь (перейдите в раздел Releases)](../../releases).

### 🛠 Инструкция по установке и запуску
1. Скачайте ZIP-архив.
2. Распакуйте его в удобное место.
3. Запустите файл BatchApkTool.exe.

### 📋 Системные требования
* Операционная система: Windows 7+
