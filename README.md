## Русский
Batch ApkTool - это мощная оболочка, объединяющая несколько инструментов для работы с файлами APK и взаимодействия с устройством через adb.
Системные требования: Windows 7+

## English
Batch ApkTool is a powerful TUI that combines several tools for working with APK files and interacting with a device via ADB.
System Requirements: Windows 7+
